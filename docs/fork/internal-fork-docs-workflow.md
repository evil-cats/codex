# Внутренний workflow документации fork

## Статус

Карточка выведена из активного fork-инвентаря. Она не описывала самостоятельную
кодовую fork-доработку, а смешивала правила и механизмы с разными владельцами.

Код и правила при этом не откатывались. `status: reverted` используется как
поддерживаемый fork-workflow terminal status, чтобы карточка больше не участвовала
в миграции и проверке активных доработок.

## Актуальные владельцы

- `AGENTS.md` определяет допустимую область внутренней документации в `docs/`;
- skill `fork` владеет форматом карточек, migration workflow и своими проверками;
- `docs/.markdownlint-cli2.yaml` владеет локальными правилами Markdown.

Собственные изменения этих владельцев проверяются и сопровождаются в их
контексте, без отдельной owner-карточки документационного workflow.

## Историческая совместимость

Файл сохранён по прежнему пути, потому что на него ссылаются завершённые
migration map и отчёты прошлых версий. Эти ссылки являются историческими и не
возвращают карточку в активный fork-инвентарь.
